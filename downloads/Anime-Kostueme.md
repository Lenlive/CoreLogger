# Anime-Kostüme — Vanilla Java 26.3

Download: `Anime-Kostueme-Vanilla-26.3.zip`

ZIP nicht entpacken. Im Minecraft-Client unter Optionen → Ressourcenpakete →
Paketordner öffnen ablegen und aktivieren. Kein Plugin, keine Mods erforderlich.
Das Paket gehört nicht in den Paper-plugins-Ordner. Jeder Spieler aktiviert
es auf seinem eigenen Client.

13 Kostümtexturen: Erwachsene kalte/gemäßigte/warme Kühe und Schweine,
rote/braune Mooshrooms, Hexen und vier Illagerarten (Diener, Magier,
Illusionist, Plünderer). Türkis-violette Stoffe, Schleifen und goldene Ränder.
Tier-Mobs mit normalen Kostümen, humanoide Outfits vollständig bekleidet.
Babyvarianten und alle übrigen Mobs bleiben unverändert. Keine zusätzlichen
Körperformen: Vanilla-Ressourcenpakete können diese Modelle nicht verändern.

Format 97.1 für Minecraft Java 26.3, anhand der Versionsmetadaten geprüft.
Texturen mit Bildgenerierungswerkzeug erstellt; anschließend mit Zustimmung
des Nutzers per Skript auf die Original-UV-Flächen übertragen. Vierfache
Vanilla-Auflösung, keine Shader oder zusätzlichen Client-Mods erforderlich.
ZIP/PNG-Dateien, Original-Transparenz und unveränderte UV-Flächen geprüft.
Noch kein visueller Live-Test im Minecraft-Client. Bitte mögliche
Texturpassungen an einzelnen Modellvarianten im Spiel kontrollieren.
